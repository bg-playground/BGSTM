# Testing Templates

This directory contains the canonical BGSTM testing templates. BGSTM has **six core methodology phases**; templates may support one or more phases and may also be used in specialized applied scenarios.

## Core Templates

- [Test Plan Template](test-plan-template.md) — planning, scope, strategy, resources, and schedule
- [Risk Assessment Template](risk-assessment-template.md) — risk identification, scoring, mitigation, and tracking
- [Test Case Template](test-case-template.md) — detailed test scenarios and execution records
- [Traceability Matrix Template](traceability-matrix-template.md) — requirements-to-test coverage and defect linkage
- [Test Execution Report Template](test-execution-report-template.md) — execution progress, status, and metrics
- [Defect Report Template](defect-report-template.md) — consistent defect documentation and lifecycle tracking
- [Test Summary Report Template](test-summary-report-template.md) — final quality assessment and release recommendation

## Specialized Applied Template

### NATAegisFlow Artifact Workflow Checklist

[NATAegisFlow Artifact Workflow Checklist Template](nataegisflow-artifact-workflow-template.md) supports ETL/data-pipeline semantic-validation work that uses NATAegisFlow evidence, policy gates, approvals, and audit records.

This is a specialized template for applying the existing six BGSTM phases. It does **not** define a seventh BGSTM phase.

See the [ETL Semantic Validation Applied Example](../examples/etl-semantic-validation-example.md) for the Phase 1–6 mapping.
