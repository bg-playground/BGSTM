# Testing Framework Examples

BGSTM defines **six core testing phases**. The examples below demonstrate those phases and show how the same methodology can be adapted to specialized scenarios.

## Start Here — One Feature Through All Six Phases

New to BGSTM? Begin with the [End-to-End Six-Phase Worked Example](six-phase-checkout-worked-example.md). It follows one guest-checkout feature from risk and planning through test design, environment preparation, execution, analysis, and the final release recommendation, with the relevant BGSTM artifacts linked at each phase.
