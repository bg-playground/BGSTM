# Testing Framework Examples

This directory contains practical examples showing how to apply the **six-phase BGSTM methodology** in real-world testing work.

## Core Phase Examples

1. **[Test Planning](test-plan-example.md)** — complete test planning example
2. **[Test Case Development](test-case-suite-example.md)** — detailed test case suite
3. **[Test Environment Preparation](environment-setup-example.md)** — environment setup and readiness example
4. **[Test Execution](defect-report-example.md)** — defect documentation and execution evidence
5. **Test Results Analysis** — [Risk Assessment](risk-assessment-matrix-example.md) and [Testing Schedule](testing-schedule-example.md)
6. **[Test Results Reporting](traceability-matrix-example.md)** — traceability, coverage, and reporting example

BGSTM has exactly six methodology phases. Specialized scenarios are examples of applying those phases; they do not add phases to the methodology.

## Applied Example: ETL Semantic Validation

- **[ETL Semantic Validation Applied Example](etl-semantic-validation-example.md)** — shows how ETL/data-pipeline semantic validation maps across BGSTM Phases 1–6.
- **[NATAegisFlow Artifact Workflow Example](nataegisflow-artifact-workflow-example.md)** — worked ETL artifact validation using NATAegisFlow evidence.
- **[AegisFlow BGSTM Adoption Retrospective and Sign-off](nataegisflow-bgstm-pilot-retrospective.md)** — lessons, process changes, rollout readiness, and sign-off from the applied workflow.

Use these materials when adapting BGSTM to ETL or data-pipeline work that needs semantic-validation evidence, policy gates, approvals, or auditability.
